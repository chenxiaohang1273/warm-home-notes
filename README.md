# Warm Home Notes (starter website)

This is an educational, single-page static website. It contains no affiliate links, no analytics, no claimed product testing, and no backend.

## Edit locally
Open `index.html` in any text editor to change content. Double-click the file in your browser to preview.

## Upload to GitHub
Create a repository named `warm-home-notes`. Choose **Add file > Upload files**, then upload **index.html** and **README.md** (not the ZIP). Commit changes.

## Deploy using Cloudflare Pages
In Cloudflare dashboard choose Workers & Pages > Create > Pages > Connect to Git and select your GitHub repository. For a plain HTML site choose branch `main`, no build command (or `exit 0` if required), and build output directory `/` (repository root). Deploy, then check the `*.pages.dev` URL.

## Before using commercially
Replace starter owner/contact details with accurate information. Update the privacy notice to reflect your actual hosting, analytics, cookies and tracking. Verify any product claims and applicable safety information. Secure written permissions for any paid-search affiliate offers; prominently label affiliate links. Do not claim hands-on product testing unless it was actually done.
